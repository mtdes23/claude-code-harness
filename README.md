# Claude Code: Hệ Thống Tự Chạy (Skill · Hook · Agent) & Chợ Skill AI

Website chính thức giới thiệu **Khóa Học Claude Code: Hệ Thống Tự Chạy** và sàn thương mại điện tử **Chợ 200+ Skill & Plugin AI Thực Chiến**.

## 🌟 Tính Năng Nổi Bật

- **Khóa học Claude Code 5 Buổi Zoom (499k)**:
  - Buổi 1: Giao việc & Phân quyền (Phiếu giao việc 5 ý, Permission, Video motion)
  - Buổi 2: Bộ não của hệ thống (CLAUDE.md đa tầng, Auto memory, Handoff)
  - Buổi 3: Skill và Plugin (SKILL.md, học style video mẫu, đóng gói plugin 1 lệnh)
  - Buổi 4: Hook, Token và Context (5 mốc hook vòng đời, chặn tốn tiền)
  - Buổi 5: Đội Agent và Vận hành tự động (NEXUS Subagent 3 vai, MCP, Cron đêm)
- **Chợ 200+ Skill & Plugin AI Thực Chiến**:
  - Đóng gói sẵn từ source code thực tế (CapCut, Remotion, VieNeu TTS v3 Turbo, Cinematic Grading, Blender, UI/UX Pro Max, Agency Agents...)
  - Bộ lọc danh mục, tìm kiếm real-time và modal hướng dẫn chi tiết từng skill.
- **Giỏ hàng & Cổng thanh toán VietQR động**:
  - Hỗ trợ mã giảm giá `HOCVIEN50` và `CLAUDEAI`.
  - Sinh mã VietQR chuyển khoản tự động kèm cú pháp định danh duy nhất.
- **Tối ưu hóa UI/UX**:
  - Dark mode sang trọng, responsive 100% trên điện thoại và máy tính.
  - Interactive Terminal mô phỏng quá trình Claude Code thực thi tác vụ.

## 🚀 Cài Đặt & Chạy Cục Bộ

Trang web được xây dựng thuần HTML5, Tailwind CSS và JavaScript hiện đại:
1. Clone repository về máy:
   ```bash
   git clone https://github.com/mtdes23/claude-code-harness-course.git
   ```
2. Mở trực tiếp file `index.html` trên bất kỳ trình duyệt nào.

## 🌐 Triển Khai (Deployment)
Dự án được triển khai tĩnh siêu tốc trên [Vercel](https://vercel.com).
